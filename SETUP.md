# Setup — Perfume E-Commerce Skeleton

This zip contains only the **application-specific** files (migrations, models,
controllers, routes, views, JS/CSS, config). Laravel's own framework files
(vendor/, bootstrap/, public/index.php, artisan, etc.) are identical for every
project and are generated by Composer, so you install those first, then drop
this skeleton on top.

## 1. Create the base Laravel project

```bash
composer create-project laravel/laravel perfume-ecommerce
cd perfume-ecommerce
```

## 2. Copy this skeleton in

Copy every folder from this zip into the new project root, merging with what
Composer generated (say yes to overwrite `routes/web.php`):

```
app/Http/Controllers/  → app/Http/Controllers/
app/Http/Middleware/   → app/Http/Middleware/
app/Models/            → app/Models/
database/migrations/   → database/migrations/
database/seeders/      → database/seeders/
resources/css/         → resources/css/
resources/js/          → resources/js/
resources/views/       → resources/views/
routes/web.php         → routes/web.php
public/assets/         → public/assets/
package.json, vite.config.js, tailwind.config.js, postcss.config.js  → project root
.env.example           → merge into your .env
```

## 3. Register the `admin` / `customer` middleware aliases

Open `bootstrap/app.php` and add the aliases inside `withMiddleware`:

```php
->withMiddleware(function (Middleware $middleware) {
    $middleware->alias([
        'admin' => \App\Http\Middleware\IsAdmin::class,
        'customer' => \App\Http\Middleware\IsCustomer::class,
    ]);
})
```

## 4. Install dependencies

```bash
composer install
composer require laravel/ui   # not required, but handy if you add auth scaffolding later
npm install
```

`package.json` already lists everything the animations need: `gsap`,
`alpinejs`, `tailwindcss`, `@tailwindcss/forms`.

## 5. Environment & database

```bash
cp .env.example .env      # or merge the DB_* values into your existing .env
php artisan key:generate
```

Create a MySQL database matching `DB_DATABASE` in `.env`, then:

```bash
php artisan migrate
php artisan db:seed        # creates an admin user, a customer, categories & sample perfumes
php artisan storage:link   # required — admin-uploaded product images live in storage/app/public
```

Seeded logins:
- **Admin:** admin@maisonnoir.example / password
- **Customer:** customer@maisonnoir.example / password

## 6. Add your logo & video

See:
- `public/assets/images/logo/README.md`
- `public/assets/video/README.md`

Short version: your logo goes at `public/assets/images/logo/logo.svg`
(+ `favicon.png`), your video goes at
`public/assets/video/perfume-showcase.mp4`. Nothing else needs to change —
the Blade views already point at those exact paths.

## 7. Run it

```bash
php artisan serve
npm run dev     # in a second terminal, for Vite + hot reload
```

Visit `http://localhost:8000`.

## What's implemented vs. stubbed

This is a working **skeleton**, not the finished store:
- ✅ Full DB schema, models & relationships, routes, controllers for the whole
  customer + admin flow (browsing, cart, wishlist, checkout/COD, order
  history, admin CRUD for perfumes/categories/orders/customers)
- ✅ The full animation system (loader, custom cursor, nav, hero, scroll
  reveals, product-card hovers, and the scroll-scrubbed video section)
- ✅ Auth (register/login/logout) with role-based redirect + middleware
- 🔲 Not yet wired: payment gateway beyond "Cash on Delivery", email
  notifications, live search-as-you-type, image optimization/WebP pipeline,
  automated tests — these are exactly the remaining TODO items from your
  list once you ask me for the to-do list next.
